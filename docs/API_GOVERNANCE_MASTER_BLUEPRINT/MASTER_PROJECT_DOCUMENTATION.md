# المرجع الشامل للمشروع
**الإصدار: 0.1 — مسودة هندسية للمراجعة، 27 نوفمبر 2026.** جميع القرارات الجديدة مقترحة وليست اعتماداً أو شهادة جاهزية. لا تعديل للتطبيق أو البيانات.
## الغاية
منصة مؤسسية تدير أدلة توثيق API الحقيقية بين مزود ومستهلك: تسجل العلاقة، تجمع ملفات متفاوتة، تتحقق من اكتمالها وأمنها، تدير مراجعتها واعتمادها وتغييراتها ثم نشر المسموح منها. ليست API Gateway، ولا محرراً شاملاً للوثائق، ولا منصة تشغيل API. ينفذ المطور التغييرات الفنية خارج النظام.
## القصة التشغيلية
مسؤول التهيئة يعرف أغراض الملفات والقوالب والمسارات؛ مسؤول الوثائق يسجل علاقة ومجموعة ويعين المطور؛ المطور المخول ينشئ التكامل وإصداراً يرقمه يدوياً، ثم مسودة. يرفع الملفات من جهازه. يفحص الخادم البايتات في حجر خاص، ولا يعد الملف نظيفاً عند تعطل المحرك. يعرض النظام نقص المتطلبات. عند تقديم المرشح، تثبت قائمة نسخ الملفات والبصمات والقالب والمسار. المراجع يقرأ الملفات النظيفة خارج المنصة أو معاينة آمنة محدودة ويسجل ملاحظاته داخلها. ينتقل القرار للمرحلة التالية أو يرجع/يرفض مع سبب. كل تصحيح بعد التقديم يولد مرشحاً جديداً وفق التوصية. آخر مرحلة تكمل الاعتماد؛ معتمد نهائي مستقل فقط إذا أقرته الجهة. شهادة منفصلة توثق الأسماء والتواريخ والقرارات والبصمة. الناشر المخول يختار ملفات معتمدة وجمهوراً؛ لا نشر تقني للـAPI. بعد الاعتماد، يبدأ طلب تغيير إذا تغير المحتوى، لا تعديل مباشر للملف.
## مصادر الحقيقة
الملف = بايتات محفوظة + hash؛ سجل القرار = قاعدة البيانات؛ الحزمة = manifest مثبت؛ النشر = سجل اختيار وجمهور؛ رقم API = المطور المخول. الفصل بين الإذن والتعيين والأهلية. لا استثناء إداري بالاسم. العلاقة مع المنصة المؤسسية الشاملة وظيفية فقط بحسب DEC-001؛ الدمج التقني غير محسوم.
## مسار القراءة
- 03–14: المتطلبات وقواعد الملفات والمراجعة والإصدارات والتغييرات والصلاحيات.
- 15–18: السيناريوهات والمخططات والواجهات والنموذج التوضيحي.
- 19–23: المعمارية والبيانات والعقود والأمن والاختبار.
- 24–30: المصدر المفقود وحالة التنفيذ وخطة الاستكمال والتتبع والجاهزية.
## مبدأ الاعتماد
جميع ADR-P مقترحات إلا العناصر المحفوظة من القرارات السابقة. لا يطبق الفريق أي تغيير جوهري قبل موافقة المالك. لا يوجد دليل مستقل حالي على نجاح فحص الملفات أو إكمال إعادة بناء UI. لا يمكن الادعاء أن المشروع لم يبق فيه إلا البرمجة قبل حسم هذه المسائل.
