# القرارات المفتوحة (لا تنفذ قبل اعتمادها)
| ID | السؤال المؤسسي | التوصية | صاحب القرار |
|---|---|---|---|
| OD-01 | هل يوجد معتمد نهائي مستقل؟ | لا إلزام؛ مرحلة اختيارية إذا مسؤولية متميزة | مالك + حوكمة |
| OD-02 | منع اعتماد الشخص لعمله والتفويض؟ | شرط فصل واجبات سياقي؛ بديل مخول ومدقق | حوكمة + مالك |
| OD-03 | هل الشهادة المستقلة كافية قانونياً؟ | سجل نظام + manifest؛ توقيع رقمي فقط إذا مطلوب | قانون/حوكمة |
| OD-04 | شروط القالب وحدود الملفات والاحتفاظ؟ | قائمة حقول سياق معتمدة وحدود لكل غرض؛ لا مدة مفترضة | مالك + IT |
| OD-05 | تغيير بعد الاعتماد؟ | طلب حتى التحريري، مسار مبسط، مراجعة جديدة وإعادة جميع المراحل في MVP | مالك |
| OD-06 | الجمهور والتعايش والإيقاف؟ | نشر يدوي subset وجمهور؛ إيقاف صريح | مالك + أصحاب البيانات |
| OD-07 | Word الآلي؟ | PoC قبل التجميد فقط؛ إذا لا جدوى استخدم الشهادة | مالك + هندسة |
| OD-08 | RPO/RTO وحجم وحمل وسياسة النشر؟ | قياس وتحديد أهداف مع IT قبل UAT | IT + مالك |
| OD-09 | مطابقة baseline الحالي ونسخة المصدر؟ | تصدير فرع محلي نظيف، مصالحة المعرفات | مالك/فريق تطوير |
| OD-10 | آلية اختيار المراجع من الدور؟ | task claim ذرّي أو تعيين صريح حسب baseline؛ تحقق الصلاحية وقت القرار | مالك + حوكمة |
