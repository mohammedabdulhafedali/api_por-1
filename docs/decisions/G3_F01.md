# سجل اعتماد السياسات والجاهزية — F01

مرجع القرار: موافقة المالك في المحادثة «اعتمدها وابدأ تنفيذ المرحلة التالية»، بعد عرض حزمة v1.2 والسياسات التشغيلية المتبقية. هذا الملف يثبّت القواعد المحددة في مقترحات 09_G3_status، لا يختلق قرارات غير محددة ولا يدعي نجاح اختبارات التطبيق.

## قواعد معتمدة للتخطيط والتنفيذ في مهامها

| القرار | السياسة | أثر التنفيذ |
|---|---|---|
| OP-01 / CR-PLAN-01 | تسجيل التدقيق إلحاقيًا منذ S02/S03 واختبار التفويض تدريجيًا، مع بقاء واجهة العرض في P05/S13 | قبل أي عملية حساسة؛ لا تغيير في عدد المهام أو السبرنتات |
| OP-02 | الرفض ينهي المحاولة؛ طلب جديد مرتبط بها. الإعادة تسمح بالتعديل وإعادة التقديم مع التاريخ، والعودة إلى أول مرحلة عند تغيير المحتوى. تعثر الدور يوقف المعاملة بلا موافقة تلقائية | W01–W06؛ لا تجاوز للتعيين أو الصلاحيات |
| OP-03 | فشل إنتاج مشتق Word لا يمحو قرار المراجع، لكنه يمنع نشر مشتق غير متحقق. معالجة الفشل تحفظ الأصل والقرار وسجل الخطأ | V08/W03/P01؛ اختبار القوالب قبل الاعتماد التقني |
| OP-04 | يمنع الإيقاف العادي لإصدار مستخدم حتى تعيين بديل صالح ومنشور | P02/P03؛ لا تنفيذ لمسار طوارئ غير مفصل |
| OP-05 | نسخة عمل نشطة واحدة لكل مصدر وطلب تغيير، مع منع التعارض بالتزامن. وثيقة واحدة لكل مزود ومستهلك ومجموعة، وتكامل واحد لكل وثيقة | D01/V06/W05؛ قيود فعلية وترحيلات في مهامها |
| AUTH-01 | حسابات محلية ASP.NET Core Identity | I01/I02؛ مصدر الهوية محسوم |
| AUTHZ-01 | استثناء المستخدم مقدم؛ السحب الصريح بين الأدوار على الوثيقة يغلب المنح. صلاحية الإجراء العامة مطلوبة أيضًا | I03–I07/W02؛ لا حذف صلاحيات ولا حظر ثابت باسم الدور |

## شروط باقية لا يغطيها اعتماد قاعدة عامة
- I01: آلية مؤسسية مؤكدة للتحقق من هوية المستلم وتسليم رمز التفعيل والاستعادة، ومهل الجلسة والرموز والقفل. لا SMTP مفترض ولا كلمة مرور مؤقتة مكشوفة. توثق القيم قبل التنفيذ.
- V08: عينات Word فعلية مختلفة، اختبار البنية والتنسيق. لا ادعاء توافق شامل.
- W02: المنح السياقي الآلي غير معتمد؛ يبقى معطلًا. يجب توفر منح قائم وأهلية الدور، وإلا تعثر قابل للمعالجة من مخول.
- P02/P03: لا مسار إيقاف طارئ قبل تحديد ضوابطه.
- قبل الاختبارات والنشر: أهداف الأداء والاستعادة والاحتفاظ، والتحقق من بيئة IT والفحص والتخزين. لا نشر قبل B4 والتفويض المنفصل.

## تقييم البوابات
B0 لنطاق F01: مراجع معتمدة، بيئة ملفات محلية معزولة، ممنوع استخدام بيانات المؤسسة، وتوضيح القرارات المؤجلة. يمكن تنفيذ F01 بتفويض المالك. G3 الشامل ما زال مشروطًا بالأمور أعلاه، ولا يمثل جاهزية إنتاجية. لا تغيير في العدد: 59 مهمة / 14 سبرنتًا. يعاد فحص الفجوات قبل المهمة المتأثرة. هذا السجل يتقدم على حالة المقترحات التاريخية في v1.2، دون تعديل الأرشيف الأصلي.
