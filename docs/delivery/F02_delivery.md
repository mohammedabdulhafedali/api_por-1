## 3. التزام الهوية البصرية ونطاق F02
- تطبيق الألوان المعتمدة في `02_UX_UI_v1.2.md` حرفيًا للثيمين النهاري والليلي:
  - خلفية الصفحة: نهاري `#f8fafc` (`rgb(248, 250, 252)`) / ليلي `#1a2d45` (`rgb(26, 45, 69)`)
  - الشريط الجانبي والعلوي: نهاري `#ffffff` (`rgb(255, 255, 255)`) / ليلي `#243d5c` (`rgb(36, 61, 92)`)
  - البطاقات واللوحات: نهاري `#ffffff` (`rgb(255, 255, 255)`) / ليلي `#2b4870` (`rgb(43, 72, 112)`)
  - الحقول: نهاري `#ffffff` (`rgb(255, 255, 255)`) / ليلي `#1c3250` (`rgb(28, 50, 80)`)
  - الأزرار الرئيسية: نهاري `#4f46e5` (`rgb(79, 70, 229)`) / ليلي `#6366f1` (`rgb(99, 102, 241)`)
  - ألوان الحالة: نجاح `#10b981` (`rgb(16, 185, 129)`) / فشل `#f43f5e` (`rgb(244, 63, 94)`) / تحذير `#f59e0b` (`rgb(245, 158, 11)`)
- تطبيق الخطوط المعتمدة: `Tajawal` للعناوين العربية، `Readex Pro` للنصوص العربية، `Outfit` للإنجليزية، و`JetBrains Mono` للمسارات والمعرفات التقنية المعزولة باتجاه `LTR`.
- دعم تبديل اللغة `AR ⇄ EN` مع اتجاه `RTL ⇄ LTR` وحفظ التفضيلات في `localStorage`.
- القائمة الجانبية قابلة للطي مع فتح قسم واحد فقط في كل لحظة بالترتيب المعتمد: «الأنظمة والجهات» ← «الإعدادات» ← «الإدارة» ← «وثائق API» ← «التكاملات».
- عنوان الصفحة في الشريط العلوي دون تكرار كتلة عنوان/وصف في أعلى المحتوى (`PRD-06`).
- حوار مركزي موحد (`Modal`) لرسائل النجاح والتحذير والخطأ دون استخدام `Toast`.
- لا يوجد منطق أعمال أو مصادقة أو صلاحيات وهمية أو اتصال بخادم.

## 4. نتائج الفحص والبناء والاختبارات التفاعلية في المتصفح
- `npm run typecheck` (`tsc -b`): نجح دون أي أخطاء (`exit code 0`).
- `npm run build` (`tsc -b && vite build`): نجح في `1.72s` وأنتج حزمة `dist/` (`exit code 0`).
- **الاختبارات التفاعلية في المتصفح (Microsoft Edge Chromium عبر CDP على `http://127.0.0.1:5173/`):**
  - **أخطاء الكونسول والاستثناءات:** `consoleErrors: []` (صفر)، `runtimeExceptions: []` (صفر).
  - **الحالة الابتدائية (عربي + نهاري):** `lang="ar"`, `dir="rtl"`, `data-theme="light"`, الخلفية `rgb(248, 250, 252)` (`#f8fafc`)، الشريط الجانبي والعلوي والبطاقات والحقول `rgb(255, 255, 255)` (`#ffffff`)، الزر الرئيسي `rgb(79, 70, 229)` (`#4f46e5`).
  - **القائمة الجانبية القابلة للطي (قسم واحد مفتوح):** التحقق من الأقسام الـ 5 بالترتيب المعتمد؛ عند النقر على «الإعدادات» أصبح القسم المفتوح الوحيد `["الإعدادات"]`، وعند النقر على «وثائق API» أصبح القسم المفتوح الوحيد `["وثائق API"]`.
  - **تبديل المظهر إلى الليلي وحفظ مدخلات النموذج:** عند إدخال نص في الحقل التجريبي وتبديل المظهر إلى `dark`، تم حفظ `api_gov_ui_theme="dark"` في `localStorage` وبقيت قيمة الحقل محفوظة (`"اختبار حفظ المدخلات"`)، وتحدثت الألوان المحسوبة فعليًا إلى: الخلفية `rgb(26, 45, 69)` (`#1a2d45`)، القائمة والعلوي `rgb(36, 61, 92)` (`#243d5c`)، البطاقات `rgb(43, 72, 112)` (`#2b4870`)، الحقول `rgb(28, 50, 80)` (`#1c3250`).
  - **تبديل اللغة (`AR ⇄ EN`):** عند النقر على `EN` تحولت الصفحة إلى `lang="en"`, `dir="ltr"` وتحدثت العناوين والأقسام إلى الإنجليزية (`Systems & Entities`, `Settings`, `Administration`, `API Documents`, `Integrations`)، وعند النقر على `AR` عادت إلى `lang="ar"`, `dir="rtl"`.
  - **حوار الرسائل المركزي (`Modal`) وإعادة التركيز:** عند فتح `Modal` النجاح ظهر العنصر `[role="dialog"]` باللون المعتمد `rgb(16, 185, 129)` (`#10b981`) وأُغلق بنجاح عند النقر على زر التأكيد؛ وعند فتح `Modal` الخطأ ظهر باللون `rgb(244, 63, 94)` (`#f43f5e`) وعند إغلاقه عاد التركيز تلقائيًا إلى الحقل `#sample-text-input`.
