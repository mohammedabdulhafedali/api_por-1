## الجاهزية حسب العمل
- S01 (F01 ثم تبعياته): يمكن بدء العمل المحلي المعزول **بعد تفويض صريح للتطوير**؛ لا يحتاج إغلاق السياسات اللاحقة. لا يبدأ تلقائيًا.
- S02 وما بعده: شروط الفجوات أعلاه بحسب المهمة؛ لا يمكن تجاوزها. اختبار الإنتاج والنشر غير معتمدين بعد.

## قرارات التشغيل المقترحة (ليست معتمدة تلقائيًا)
1. تدقيق مبكر + اختبار تفويض مع كل وحدة؛ سجل أحداث إلحاقي، وواجهة العرض لاحقًا.
2. المرفوض نهائي لتلك المحاولة؛ طلب جديد مرتبط به. المعاد للتعديل يعاد تقديمه مع حفظ التاريخ؛ يوصى بالرجوع لأول مرحلة بعد تغير المحتوى. تعثر الدور لا يعني موافقة تلقائية.
3. Word: فشل إنشاء مشتق لا يمحو قرار المراجع؛ يمنع نشر مشتق غير متحقق، ويحدد مسار إصلاح قبل النشر. لا استبدال للأصل.
4. إيقاف إصدار مستخدم: منع الإيقاف العادي حتى تعيين بديل منشور صالح، مع مسار طوارئ لا ينفذ قبل اعتماد ضوابطه.
5. نسخة عمل نشطة واحدة لكل مصدر/طلب تغيير، مع تحقق تزامن. وثيقة فريدة حسب المزود والمستهلك والمجموعة (وتبقى العلاقة 1:1 مع التكامل)؛ لا يمنع اختلاف المجموعة.
6. آلية تسليم رمز الحساب والتحقق من الهوية، مدد الجلسات والرموز ومقاييس الجودة: تحسم قبل المهام المعنية بالتنسيق مع الجهة المختصة.

**لا حاجة إلى إعادة السؤال عن المكدس أو قرار التعارض أو مصدر الهوية.** المطلوب اعتماد ما تبقى بحسب التوقيت، وليس إعادة التصميم من الصفر.
