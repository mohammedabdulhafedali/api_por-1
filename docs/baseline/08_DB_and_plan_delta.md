# أثر القرارين على قاعدة البيانات وخطة التطوير

المخطط المنطقي الأصلي 43 جدولًا محفوظ في المرجع. لا يُنفذ كـDDL مباشر. **تعديل تصميمي مطلوب في F05/I01:** دمج نموذج ASP.NET Core Identity مع UUID المستخدم، وتحديد حقول بيانات الاعتماد (password hash, normalized login, security stamp, concurrency stamp, lockout) وجداول التذاكر/الرموز التي يتطلبها التنفيذ؛ لا تنشئ سجل مستخدمين مكررًا دون رابط فريد. قيود التفرد لـ user_roles(user_id,role_id)، وuser_permission_overrides(user_id,permission_id)، وdocument_role_permissions(document_id,role_id,permission_id)، وdocument_user_permissions(document_id,user_id,permission_id). GRANT/REVOKE فقط في حقول decision؛ عدم وجود سجل يعني عدم وجود استثناء. لا يعد هذا مخططًا ماديًا معتمدًا؛ تراجع ترحيلات Identity الفعلية مع مخطط DB عند I01. الصلاحية الجديدة users.password.reset تضاف إلى القاموس بوصفها قابلة للمنح والسحب، لا امتيازًا ثابتًا.
