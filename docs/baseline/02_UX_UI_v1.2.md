# خط الأساس الموحد للواجهات UX/UI — منصة حوكمة وثائق APIs

**الإصدار:** v1.2 — 24 نوفمبر 2026 · **الحالة:** تجميع موحد للتصاميم المعتمدة، خط أساس موحد وفق القرارات المعتمدة؛ المرجع HTML الأخير **معاينة فقط** لا كود إنتاج.

## 1. التنقل والهيكل

**روابط مستقلة:** لوحة التحكم، البحث والاستعراض، بوابة المستهلك (إذا خُوّل).  
**أقسام قابلة للطي، واحد مفتوح في كل لحظة:**
1. الأنظمة والجهات: أنظمة الشركة، الجهات المستهلكة، الأنظمة المزودة.
2. الإعدادات: أنواع الملفات، متطلبات الملفات، مسارات الاعتماد، أنواع طلبات التغيير.
3. الإدارة: المستخدمون، الأدوار والصلاحيات، سجل التدقيق.
4. وثائق API: القائمة، إضافة وثيقة، تفاصيلها، تعديلها، صلاحيات كل وثيقة.
5. التكاملات: القائمة، الإضافة، التفاصيل (الملفات/المراجعات/الإصدارات/طلبات التغيير/سجل التاريخ/النشر).

**القاعدة:** «إضافة» و«تعديل» هما صفحتان داخل التطبيق، وليس Modal. **الرسائل** وحدها Modal، مع تأكيد/إلغاء أو «حسنًا». لا تكرار لكتلة العنوان والوصف أعلى المحتوى؛ الشريط العلوي يعرض عنوان الصفحة.

### صفحات فرعية مستقلة إضافية دون وحدات قائمة جانبية جديدة

- **UI-15A — صلاحيات مستخدم** من زر «الصلاحيات»؛ جدول شامل، بيان الموروث/الإضافي/المسحوب، إعادة تطبيق الموروث، تأكيد الحفظ.
- **UI-21A — صلاحيات وثيقة** من إجراءات الوثيقة؛ جدول المستخدمين والأدوار مع الصلاحيات على الوثيقة والاستثناءات الفردية؛ وثيقة مقيدة افتراضيًا.
- **UI-05A — إضافة/تحرير مرحلة** صفحة كاملة بعنوان اسم المرحلة ودورها وترتيبها فقط؛ **بدون نوع المرحلة أو مستخدم مكلف**.
- صفحات إضافة/تعديل مستقلة حيث تنطبق، حتى لو لم يظهر كل منها كرابط في القائمة.

## 5. حالات الواجهة والمعايير

- كل نموذج يعرض الحقول الإلزامية بوضوح، أخطاء تحقق محددة، ورسائل حالة عبر Modal لا Toast.
- عند عدم وجود إذن لقراءة الوثيقة لا تظهر في البحث/القوائم/البوابة، ولا تُعاد من API حتى بمعرف مباشر. يجب اختبار عدم تسريب اسم الملف أو وجود الوثيقة.
- عند قرار مرحلة من عضو واحد مؤهل تُغلق المرحلة لغيره؛ يمكن لكل عضو آخر رؤية النتيجة إذا كان مخولًا.
- السحب الفردي المعلن يأخذ الأولوية في واجهة المصفوفة؛ تضارب دورين على نفس الوثيقة **معلّق في ADR** ولا يُخمن من لون checkbox.
- عمود «الجهة المستهلكة» والتبويب يحافظان على تمييز إصدار API عن مراجعة التوثيق والملف الفعلي.

## 6. الصلاحيات وسير العمل — نقطة تحتاج قرارًا

سلوك واجهة المصفوفة عند تعارض منح/سحب على مستوى الأدوار أو التكليف سيتم اختباره بعد اعتماد `03_ADR_أولوية_الصلاحيات_مقترح.md`. لا يجوز تنفيذ أولوية غير معتمدة وكأنها متطلب نهائي.

## 7. حالة التسليم

تكتمل مطابقة هذا النص للقرارات BAS-01..10، مع اعتماد أولوية الصلاحيات ومصدر المصادقة المحلي؛ لا يعني اجتياز G3 الكامل حتى إغلاق الفجوات المتبقية. لم تتحول معاينة HTML إلى React ولم يجر اختبار تطبيق الإنتاج.
