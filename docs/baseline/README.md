# API Governance — حزمة تسليم هندسية v1.2

**اقرأ أولًا:** `09_G3_status.md` ثم `01_PRD_v1.2.md` و`02_UX_UI_v1.2.md` و`03_AUTHZ_ADR.md` و`04_Authentication.md`. قرارات المالك اللاحقة المكتوبة في v1.2 تتقدم على المراجع التاريخية. تفاصيل التصميم غير المعتمدة مصرح بها كمقترحات. لا تفسرها كإذن بتنفيذ سياسات غير محسومة.

- `05_API_catalog_v1.2.csv` و`06_API_security_v1.2.csv`: 93 عملية سابقة + 6 عقود مصادقة محلية جديدة = 99 عملية مقترحة في الكتالوج المحدث؛ لا OpenAPI تنفيذي ولا اختبارات API منفذة.
- `07_UI_API_mapping_v1.2.csv`: 32 ارتباطًا أصليًا + 6 ارتباطات مصادقة، ليست 38 شاشة مستقلة.
- `08_DB_and_plan_delta.md`: أثر القرارات على قاعدة البيانات والمهام، لا ترحيلات SQL إنتاجية.
- `10_FIRST_TASK_F01.md` و`12_Sprint_plan_v1.md`: خطة العمل وطلب أول مهمة عند تفويض التنفيذ.
- `11_Traceability_v1.2.md`: تتبع المتطلبات والمهام، و`references/` يحتفظ بالحزم المعمارية والاختبارات المخططة والنموذج المرئي الأصلي. **المراجع القديمة غير حاكمة حيث تتعارض مع v1.2.** ملف HTML مرجع UX محلي فقط؛ لا يستخدم كخادم أو مصادقة أو تطبيق إنتاجي، ولا تدخل فيه بيانات المؤسسة.
- `13_validation.json`: نتائج فحص اتساق الملفات فقط، لا نتائج اختبار تطبيق.

**المكدس المعتمد:** React 19 + TypeScript / ASP.NET Core 10 LTS / PostgreSQL 18 / EF Core 10 / Open XML SDK / Windows Server + IIS. 59 مهمة و14 سبرنتًا. الحسابات المحلية معتمدة؛ الصلاحيات قابلة للمنح والسحب. تجهيز البنية التحتية من مسؤولية IT. 

**الحالة:** تسليم مشروط لمرحلة التخطيط، G3 الكامل مفتوح بسبب شروط التشغيل المتبقية. لا تفويض ببرمجة F01 تلقائيًا، ولا نشر. لا تقدم على مهمة ذات قرار معلق. سجل نتائج كل مهمة واطلب اعتمادها قبل التالية.
