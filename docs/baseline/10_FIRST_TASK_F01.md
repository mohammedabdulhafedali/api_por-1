# مهمة F01 — تأسيس المستودع (جاهزة للتفويض لاحقًا)

انسخ النص التالي إلى وكيل البرمجة فقط عندما تعتمد بدء البرمجة:

> نفذ F01 فقط من السبرنت S01 لمشروع منصة حوكمة APIs. اقرأ README ثم PRD وUX وخطة السبرنتات وملف G3. استخدم React 19 + TypeScript وASP.NET Core 10 LTS وPostgreSQL 18 وEF Core 10 وOpen XML SDK كقرارات معتمدة. لا تنفذ F02 أو F03 أو غيرهما بعد. افحص مجلد المشروع أولًا ولا تستبدل مستودعًا موجودًا دون مبرر. أنشئ/نظم مستودع Git محليًا، وحدد مجلدات frontend وbackend وtests وdocs، وأضف README واضحًا و.gitignore مناسبًا وقواعد عدم حفظ الأسرار ومرجعًا إلى ملفات التصميم. لا تثبت خدمات على Windows Server المؤسسي، ولا تنشئ قاعدة بيانات إنتاجية، ولا تنشر أو تدفع الكود إلى جهة خارجية. راجع أن هيكل المستودع موجود، وأن الوثائق قابلة للقراءة وأن لا أسرار مدرجة. سلّم تقريرًا بالعربية: التغييرات، أدلة التحقق (الأوامر ومخرجاتها الفعلية)، ما لم يُختبر، خطوات التراجع والتوصية. توقف بعد F01 وانتظر الموافقة.

**معيار القبول:** وجود المستودع والهيكل والREADME وملفات الاستبعاد، مراجعة حالة Git، وعدم تعديل أي بيئة إنتاجية. لا ادعاء نجاح build لتطبيق لم يؤسس بعد. F02/F03 لهما تفويض منفصل وفق الخطة.
