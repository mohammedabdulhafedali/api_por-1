# S01-T02 — إعادة ضبط واجهة تسجيل الدخول (`UI-24`) لتكون احترافية ونظيفة باسم المستخدم وكلمة المرور مع أيقونات العين والوضع الليلي/النهاري المتقدمة

---

**اسم المهمة:** `S01-T02` — إعادة ضبط واجهة تسجيل الدخول (`UI-24`) لتكون احترافية ونظيفة باسم المستخدم وكلمة المرور مع أيقونات العين والوضع الليلي/النهاري المتقدمة

**الهدف:** تحويل شاشة تسجيل الدخول (`LoginPage.tsx`) والأيقونات المرتبطة بها إلى واجهة مؤسسية حية ونظيفة جدًا خالية من أي نصوص تجريبية أو تقنية أو تبويبات زائدة، وتعتمد على «اسم المستخدم وكلمة المرور»، مع أيقونة العين لإظهار/إخفاء كلمة المرور وأيقونة احترافية للوضع الليلي/النهاري.

**المخرج النهائي:**
1. تنظيف `LoginPage.tsx` بالكامل:
   - حذف الوصف التقني (`بوابة دخول موحدة للمستخدمين الداخليين والخارجيين عبر ASP.NET Core Identity...`).
   - حذف صندوق تنبيه التفعيل السفلي (`تنبيه التفعيل: تُنشأ الحسابات بواسطة مدير النظام...`).
   - حذف التذييل التقني (`UI-24 · مصادقة محلية آمنة...`).
   - حذف صف التبويبات (`تسجيل الدخول` / `تفعيل الحساب / تعيين كلمة المرور`) بالكامل بحيث تعرض البطاقة نموذج تسجيل الدخول فقط.
2. تحويل حقل الدخول الأول في `LoginPage.tsx` و`authApi.ts` إلى **«اسم المستخدم» (`Username`)** (`type="text"`, `autoComplete="username"`) بدلًا من البريد الإلكتروني.
3. استبدال زر «إظهار / إخفاء» النصي بزر أيقونة العين (`eye` / `eye-off` SVG) مدمج بأناقة داخل حقل كلمة المرور.
4. استبدال إيموجي الوضع الليلي/النهاري (`🌙` / `☀️`) بأيقونات SVG هندسية احترافية (`moon` / `sun`) في شاشة تسجيل الدخول وفي الشريط العلوي (`AppLayoutShell.tsx`).

**نطاق التنفيذ:**

  - تحديث `ReferenceIcon` في `frontend/src/components/ui/AppLayoutShell.tsx` لإضافة أيقونات SVG نظيفة ومتقنة لـ `eye` و`eye-off` و`moon` و`sun`، واستخدام `moon`/`sun` في زر تبديل المظهر في الشريط العلوي.
  - تحديث `frontend/src/api/authApi.ts` لإرسال `username` في `loginWithLocalIdentity` وقراءة `username` ضمن `AuthenticatedUser`.
  - إعادة ضبط `frontend/src/components/auth/LoginPage.tsx` و`frontend/src/styles/theme.css` لتطبيق التصميم النظيف، وحقل اسم المستخدم، وأيقونة العين داخل حقل كلمة المرور، وأيقونة الوضع الليلي/النهاري، وحذف صف التبويبات والنصوص الزائدة.
  - تحديث اختبارات الواجهة `frontend/src/__tests__/AuthFlow.test.tsx` لتطابق الواجهة النظيفة الجديدة وتتحقق من الدخول باسم المستخدم وأيقونة العين.

1. **إضافة أيقونات SVG الاحترافية (`frontend/src/components/ui/AppLayoutShell.tsx`):**
