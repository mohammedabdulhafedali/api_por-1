# S05-T02 — فصل «سياسات التغيير» كمسار مستقل وتنظيف صفحات قسم «الإعدادات» الخمس بالكامل

---

**اسم المهمة:** `S05-T02` — فصل «سياسات التغيير» كعنصر مسار مستقل في القائمة الجانبية تحت قسم «الإعدادات» وتنظيف صفحات الإعدادات الخمس بالكامل (حذف النصوص والأكواد الزائدة وشريط البحث والأعمدة الفرعية واستخدام زر `+` المدمج وزر «حذف»)

**الهدف:** جعل قسم «الإعدادات» يضم 5 عناصر مسارات مستقلة في القائمة الجانبية (`أنواع الملفات`، `قوالب متطلبات الملفات`، `مسارات الاعتماد`، `أنواع طلبات التغيير`، `سياسات التغيير`) بحيث تفتح كل صفحة جدولًا واحدًا نظيفًا تمامًا بدون أي تبويبات داخلية أو نصوص زائدة، مع زر `+` مدمج للإضافة وزر «حذف» في عمود الإجراءات.

**المخرج النهائي:**
1. **في القائمة الجانبية (`uiBaseline.ts` و`AppLayoutShell.tsx` و`App.tsx`):**
   - إضافة عنصر مستقل خامس تحت قسم **«الإعدادات»**: **«سياسات التغيير»** (`UI-06P` — `Change Policies`).
   - ربط `UI-06` بعرض جدول «أنواع طلبات التغيير» فقط، وربط `UI-06P` بعرض جدول «سياسات التغيير» فقط (حذف التبويبات الداخلية من `ChangeTypesAndPoliciesPage.tsx`).
2. **في صفحة «أنواع الملفات» (`FileTypesManagementPage.tsx`):**
   - حذف العنوان الداخلي (`قاموس أنواع الملفات... UI-04 · M04`) والوصف الطويل، وشريط البحث والتصفية، وزر الإضافة النصي الكبير.
   - حذف عمودَي `رمز القاموس` و`قالب Word` من الجدول، والإبقاء على (`الاسم الظاهر`، `الامتدادات المسموحة`، `الحد الأقصى`، `الحالة`، `الإجراءات: تعديل / تعطيل / حذف`) + زر `+` مدمج.
3. **في صفحة «قوالب متطلبات الملفات» (`RequirementTemplatesPage.tsx`):**
   - حذف العنوان الداخلي (`UI-23`) والوصف الطويل، وشريط البحث والتصفية، وزر الإضافة النصي الكبير.
   - حذف عمودَي `اللقطات التاريخية` و`الوثائق المرتبطة` وزر `اللقطات`، والإبقاء على (`اسم القالب`، `قواعد الملفات`، `الحالة`، `الإجراءات: تعديل / تعطيل / حذف`) + زر `+` مدمج.
4. **في صفحة «مسارات الاعتماد» (`ApprovalRoutesPage.tsx`):**
   - حذف العنوان الداخلي (`UI-05`) والوصف الطويل، وشريط البحث والتصفية، وزر الإضافة النصي الكبير.
   - حذف عمود `الارتباطات`، وتبسيط زر `إدارة المراحل (UI-05A)` إلى `المراحل`، والإبقاء على (`اسم المسار`، `المراحل المرتبة والدور المسؤول`، `الحالة`، `الإجراءات: تعديل / المراحل / تعطيل / حذف`) + زر `+` مدمج.
5. **في صفحتَي «أنواع طلبات التغيير» و«سياسات التغيير» (`ChangeTypesAndPoliciesPage.tsx`):**
   - حذف صف التبويبات الداخلي، والعناوين والأوصاف الطويلة، وشريط البحث والتصفية، وزر الإضافة النصي الكبير.
   - حذف عمود `السياسات` من جدول أنواع التغيير وعمود `الوثائق` من جدول سياسات التغيير، وإضافة زر `+` مدمج وزر «حذف» في كلتا الصفحتين.

**نطاق التنفيذ:**
- **المطلوب تنفيذه:** تحديث `uiBaseline.ts`، و`AppLayoutShell.tsx`، و`App.tsx`، و`FileTypesManagementPage.tsx`، و`RequirementTemplatesPage.tsx`، و`ApprovalRoutesPage.tsx`، و`ChangeTypesAndPoliciesPage.tsx`.
