# S05-T01 — إضافة نقاط النهاية لحذف عناصر إعدادات الحوكمة الخمسة في الخادم مع حماية السجلات المرتبطة

---

**اسم المهمة:** `S05-T01` — إضافة نقاط النهاية الخاصة بحذف «أنواع الملفات» و«قوالب المتطلبات» و«مسارات الاعتماد» و«أنواع التغيير» و«سياسات التغيير» في الخادم مع حماية السجلات المرتبطة

**الهدف:** توفير عمليات `DELETE` آمنة ومحمية بـ `CSRF` والصلاحيات وسجل التدقيق في الخادم لجميع كيانات قسم الإعدادات الخمسة حتى يعمل زر «حذف» في كل صفحة منها.

**المخرج النهائي:**
1. في `ConfigurationModule.cs` و`GovernanceConfigurationService.cs`:
   - `DELETE /api/v1/file-types/{fileTypeId}`: يتحقق من عدم ارتباط نوع الملف بقواعد قوالب متطلبات أو ملفات مرفوعة (`422` إن وُجد ارتباط)، ثم يحذف امتداداته وسجله ويسجل `FILE_TYPE_DELETED`.
   - `DELETE /api/v1/requirement-templates/{templateId}`: يتحقق من عدم ارتباط القالب بوثائق API قائمة (`422` إن وُجد ارتباط)، ثم يحذف لقطاته وقواعده وسجله ويسجل `REQUIREMENT_TEMPLATE_DELETED`.
   - `DELETE /api/v1/approval-routes/{routeId}`: يتحقق من عدم ارتباط المسار بوثائق API أو أنواع تغيير أو تشغيلات اعتماد (`422` إن وُجد ارتباط)، ثم يحذف مراحله وسجله ويسجل `APPROVAL_ROUTE_DELETED`.
   - `DELETE /api/v1/change-types/{changeTypeId}`: يتحقق من عدم ارتباط نوع التغيير بسياسات تغيير أو طلبات تغيير (`422` إن وُجد ارتباط)، ثم يحذفه ويسجل `CHANGE_TYPE_DELETED`.
   - `DELETE /api/v1/change-policies/{policyId}`: يتحقق من عدم ارتباط السياسة بوثائق API قائمة (`422` إن وُجد ارتباط)، ثم يحذف روابطها وسجلها ويسجل `CHANGE_POLICY_DELETED`.
2. في `masterDataApi.ts` و`governanceConfigApi.ts`: إضافة دوال استدعاء الحذف الخمس.

**نطاق التنفيذ:**
- **المطلوب تنفيذه:** تحديث `ConfigurationModule.cs`، و`GovernanceConfigurationService.cs`، و`masterDataApi.ts`، و`governanceConfigApi.ts`.
- **ما لا يدخل ضمن المهمة:** تعديل مخطط قاعدة البيانات.

**معايير الاكتمال:**
- [x] عمل نقاط الحذف الخمس بنجاح مع رفض حذف السجلات المرتبطة بوثائق أو كيانات أخرى (`422`) وتسجيل التدقيق.

**تقييم الأولوية:** `8/10` (عالية — تنفيذ إلزامي).

**مبرر التقييم:** تبعية خلفية ضرورية لعمل زر «حذف» في صفحات قسم الإعدادات الخمس.

**قرار التنفيذ:** الآن (بعد اطلاع المالك على الملف).

**الموعد النهائي:** فوري (3 دقائق).

**التحسينات المؤجلة:** لا يوجد.

**الحالة:** مكتملة.
