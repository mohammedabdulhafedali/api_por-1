# S02-T04 — استعادة أقسام وعناصر قائمتنا الجانبية الأصلية المعتمدة بنفس التنسيق الجديد + تفعيل أزرار التحكم (`📌 Pin`، `>`، و`☰`)

---

**اسم المهمة:** `S02-T04` — استعادة أقسام وعناصر قائمتنا الجانبية الأصلية المعتمدة بنفس التنسيق والألوان الجديدة + تفعيل الوظائف الحقيقية لأزرار التحكم بالقائمة (`📌 Pin`، `>`، و`☰`)

**الهدف:**
1. استعادة **أقسام وتبويبات وعناصر قائمتنا الجانبية الأصلية الخاصة بالمنصة** (`STANDALONE_NAV_ITEMS` الثلاثة + `SIDEBAR_GROUPS` الخمسة: `الأنظمة والجهات`، `الإعدادات`، `الإدارة`، `وثائق API`، `التكاملات`) دون استبدال مسمياتها أو هيكلها، ولكن **بنفس التنسيق البصري الجديد الأنيق** (رأس المكعب البنفسجي، التلوين البنفسجي المتدرج للعنصر النشط، الأيقونات الواضحة، وبدون شريط تمرير رمادي).
2. تفعيل الوظيفة الحقيقية للأزرار الثلاثة (`📌 التثبيت`، `> التصغير/الطي`، و`☰ الإخفاء/الإظهار`).

**المخرج النهائي:**
1. **عناصر القائمة الجانبية الأصلية بالتنسيق الجديد:**
   - الروابط المستقلة الـ 3 (`لوحة الداشبورد`، `البحث والاستعراض`، `بوابة المستهلك`).
   - الأقسام الـ 5 القابلة للطي (`الأنظمة والجهات`، `الإعدادات`، `الإدارة`، `وثائق API`، `التكاملات`) بجميع شاشاتها المعتمدة، منسقة بنفس التصميم الجديد.
2. **الأزرار الثلاثة الفعالة:**
   - **زر الدبوس (`📌 Pin`):** يبدل بين وضع التثبيت (`Pinned` باللون الأخضر الزمردي بحيث تبقى القائمة مفتوحة عند التنقل) ووضع عدم التثبيت (`Unpinned` بحيث تطوى القائمة تلقائيًا عند اختيار شاشة لتوسيع مساحة العمل).
   - **زر السهم (`>` / `<`):** يصغّر القائمة الجانبية إلى وضع شريط الأيقونات المصغّر (`Mini Rail` بعرض `72px`) أو يعيد توسيعها.
   - **زر القائمة (`☰` في الشريط العلوي):** يفتح ويغلق القائمة الجانبية بالكامل (أو يعيد فتحها عند طيها)، بدون إطار التركيز الأبيض المزدوج.

**نطاق التنفيذ:**
- **المطلوب تنفيذه:** تحديث `AppLayoutShell.tsx` و`theme.css`.
- **ما لا يدخل ضمن المهمة:** أي تعديل على الخادم أو الشاشات الأخرى.

**معايير الاكتمال:**
- [ ] عودة عناصر وأقسام قائمتنا الجانبية الأصلية المعتمدة (`3` روابط + `5` أقسام) بالكامل بنفس التنسيق والألوان الجديدة.
- [ ] عمل زر `📌` لتبديل تثبيت القائمة الجانبية فعليًا.
- [ ] عمل زر `>` لتصغير القائمة إلى شريط أيقونات (`Mini Rail`) وإعادة فتحها.
- [ ] عمل زر `☰` لإخفاء/إظهار القائمة الجانبية بنظافة.
