# S03-T01 — إضافة نقطة النهاية لحذف المستخدمين في الخادم مع حماية الحساب الحالي والسجلات المرتبطة

---

**اسم المهمة:** `S03-T01` — إضافة نقطة النهاية الخاصة بحذف المستخدمين (`DELETE /api/v1/users/{userId}`) في الخادم مع حماية الحساب الحالي والسجلات المرتبطة

**الهدف:** توفير عملية `DELETE /api/v1/users/{userId}` محمية بـ `CSRF` وصلاحية `users.edit` في الخادم، تمنع حذف المستخدم لنفسه أو حذف آخر مدير نظام أو حذف مستخدم مرتبط بوثائق/تعيينات مطورين/قرارات اعتماد، وتحذف المستخدم غير المرتبط بأمان مع تنظيف جلساته وأدواره واستثناءاته.

**المخرج النهائي:**
1. في `UserManagementService.cs` و`IdentityAccessModule.cs`:
   - إضافة `DeleteUserAsync(ClaimsPrincipal actorPrincipal, Guid targetUserId, CancellationToken cancellationToken)` ونقطة `DELETE /api/v1/users/{userId:guid}`.
   - التحقق من عدم حذف الحساب الحالي (`actor.Id == targetUserId`)، وعدم حذف آخر حساب إداري فعّال، وعدم ارتباط المستخدم بوثائق (`ApiDocuments.CreatedByUserId`) أو تعيينات مطورين (`IntegrationDeveloperAssignments`) أو قرارات مراحل (`WorkflowStageActions.ActedByUserId`) أو استثناءات وثائق (`DocumentPermissionExceptions.TargetUserId`) (`422` برسالة واضحة إن وُجد ارتباط).
   - حذف جلسات المستخدم (`AuthSessions`)، وأدواره (`UserRoles`)، واستثناءات صلاحياته (`UserPermissionOverrides`)، وإشعاراته (`Notifications`)، وفك ارتباط `AuditEvents.ActorUserId` لحسابات الاختبار غير المرتبطة بوثائق، ثم حذف سجل المستخدم وتسجيل `USER_DELETED`.
2. في `usersApi.ts`: إضافة دالة `deleteUserAccount(userId, lang)`.

**نطاق التنفيذ:**
- **المطلوب تنفيذه:** تحديث `UserManagementService.cs`، و`IdentityAccessModule.cs`، و`usersApi.ts`.
- **ما لا يدخل ضمن المهمة:** تعديل مخطط قاعدة البيانات.

**معايير الاكتمال:**
- [x] عمل نقطة `DELETE /api/v1/users/{userId}` بنجاح مع حماية الحساب الحالي والمراجع النشطة.

**تقييم الأولوية:** `8/10` (عالية — تنفيذ إلزامي).

**مبرر التقييم:** تبعية خلفية ضرورية لعمل زر «حذف» في شاشة المستخدمين أسوة ببقية شاشات المنصة.

**قرار التنفيذ:** الآن (بعد اطلاع المالك على الملف).

**الموعد النهائي:** فوري (3 دقائق).

**التحسينات المؤجلة:** لا يوجد.

**الحالة:** مكتملة.

**برومبت التنفيذ:**

```markdown
نفّذ المهمة S03-T01 بإضافة `DELETE /api/v1/users/{userId}` في `IdentityAccessModule` و`UserManagementService` مع حماية الحساب الحالي والسجلات المرتبطة، وربطها في `usersApi.ts`.
```
