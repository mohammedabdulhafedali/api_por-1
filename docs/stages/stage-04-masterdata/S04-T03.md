# S04-T03 — إضافة وظيفة وزر «حذف» لأنظمة الشركة ومجموعات واجهات API

---

**اسم المهمة:** `S04-T03` — إضافة وظيفة وزر «حذف» لأنظمة الشركة ومجموعات واجهات API (مع تأكيد الحذف وحماية السجلات المرتبطة بوثائق)

**الهدف:** تمكين المستخدم المخول من حذف نظام شركة (أو مجموعة واجهات API) نهائيًا عبر زر «حذف» في عمود الإجراءات بعد رسالة تأكيد (`CentralModalDialog`)، مع منع حذف النظام إذا كان مرتبطًا بوثائق API قائمة (وإزالة سجل المزود الداخلي التابع له تلقائيًا إذا لم يكن مرتبطًا بوثائق).

**المخرج النهائي:**
1. **في الخادم (`MasterDataModule.cs` و`MasterDataService.cs`):**
   - إضافة نقطة النهاية `DELETE /api/v1/company-systems/{systemId}` (تتطلب صلاحية `company_systems.edit` و`CSRF`):
     - تتحقق من عدم ارتباط النظام بأي وثيقة API كمزود أو كمستهلك (`422` برسالة واضحة للمستخدم إن وُجد ارتباط).
     - تحذف أي سجل `internal_provider_systems` غير مرتبط بوثائق تابع لهذا النظام، ثم تحذف النظام وتسجل الحدث في سجل التدقيق (`COMPANY_SYSTEM_DELETED`).
   - إضافة نقطة النهاية `DELETE /api/v1/api-groups/{groupId}` (تتطلب صلاحية `api_groups.manage` و`CSRF`):
     - تتحقق من عدم ارتباط المجموعة بأي وثيقة API (`422` إن وُجد ارتباط)، ثم تحذف المجموعة وتسجل الحدث في سجل التدقيق (`API_GROUP_DELETED`).
2. **في الواجهة (`masterDataApi.ts` و`CompanySystemsPage.tsx`):**
   - إضافة دالتَي `deleteCompanySystem` و`deleteApiGroup`.
   - إضافة زر **«حذف»** (`Delete`) في عمود الإجراءات بجانب «تعديل» و«تعطيل»، يفتح نافذة تأكيد الحذف في `CentralModalDialog` ثم ينفذ الحذف ويحدّث الجدول.

**نطاق التنفيذ:**
- **المطلوب تنفيذه:** تحديث `MasterDataModule.cs`، و`MasterDataService.cs`، و`masterDataApi.ts`، و`CompanySystemsPage.tsx`.
- **ما لا يدخل ضمن المهمة:** تعديل مخطط قاعدة البيانات (لا يحتاج Migration).

**معايير الاكتمال:**
- [ ] ظهور زر «حذف» في عمود الإجراءات في جدول أنظمة الشركة وجدول مجموعة واجهات API.
- [ ] نجاح حذف النظام غير المرتبط بوثائق بعد تأكيد الحذف، وظهور رسالة واضحة إذا كان النظام مرتبطًا بوثائق API.

**تقييم الأولوية:** `8/10` (عالية — تنفيذ إلزامي).

**مبرر التقييم:** استكمال عملية الحذف الأساسية في جدول أنظمة الشركة للعرض التجريبي.

**قرار التنفيذ:** الآن (بعد اطلاع المالك على الملف).
