# S04-T01 — فصل «مجموعة واجهات API» في تبويب مستقل بالقائمة الجانبية عن شاشة «أنظمة الشركة»

---

**اسم المهمة:** `S04-T01` — فصل «مجموعة واجهات API» في تبويب مستقل بالقائمة الجانبية عن شاشة «أنظمة الشركة»

**الهدف:** إخراج «مجموعات API» من داخل شاشة «أنظمة الشركة» ووضعها في تبويب مستقل مناسب في القائمة الجانبية باسم **«مجموعة واجهات API»** (`API Interface Groups`) تحت قسم **«وثائق API»** (أو «الأنظمة والجهات»)، بحيث تعرض شاشة «أنظمة الشركة» جدول أنظمة الشركة فقط، ويعرض تبويب «مجموعة واجهات API» جدول مجموعات واجهات API فقط.

**المخرج النهائي:**
1. إضافة عنصر مستقل في القائمة الجانبية (`uiBaseline.ts` و`AppLayoutShell.tsx` و`App.tsx`) باسم **«مجموعة واجهات API»** (`UI-04G`).
2. ربط `UI-01` بعرض أنظمة الشركة فقط، وربط `UI-04G` بعرض مجموعة واجهات API فقط، وإزالة التبويب المزدوج (`أنظمة الشركة (M01)` / `مجموعات API (M04)`) من داخل `CompanySystemsPage.tsx`.

**نطاق التنفيذ:**
- **المطلوب تنفيذه:** تحديث `uiBaseline.ts` و`AppLayoutShell.tsx` و`App.tsx` و`CompanySystemsPage.tsx`.
- **ما لا يدخل ضمن المهمة:** تعديل الخادم أو قاعدة البيانات.

- [ ] اقتصار شاشة «أنظمة الشركة» على جدول أنظمة الشركة فقط دون تبويبات داخلية.
