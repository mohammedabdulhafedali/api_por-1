# S04-T05 — تنظيف شاشة «الأنظمة المزودة» وإضافة زر `+` مدمج ووظيفة «حذف»

---

**اسم المهمة:** `S04-T05` — تنظيف شاشة «الأنظمة المزودة» بنفس النمط: تبسيط مسميي التبويبين (`مزودون داخليون` / `مزودون خارجيون`)، حذف النصوص والأكواد الزائدة وصندوق التنبيه وشريط البحث وعمود الوثائق، استبدال زر الإضافة بزر `+` مدمج، وإضافة وظيفة «حذف»

**الهدف:** جعل شاشة «الأنظمة المزودة» (`ProvidersManagementPage.tsx`) نظيفة ومباشرة تمامًا مثل شاشات «أنظمة الشركة» و«الجهات المستهلكة»، مع إتاحة حذف المزودين الداخليين والخارجيين غير المرتبطين بوثائق API.

**المخرج النهائي:**
1. **في الخادم (`MasterDataModule.cs` و`MasterDataService.cs`):**
   - إضافة `DELETE /api/v1/internal-providers/{providerId}` (يتطلب `providers.edit` و`CSRF`): يتحقق من عدم ارتباط المزود الداخلي بوثائق API قائمة (`422` إن وُجد ارتباط)، ثم يلغي تسجيله كمزود داخلي دون المساس بأصل سجل نظام الشركة، ويسجل `INTERNAL_PROVIDER_DELETED`.
   - إضافة `DELETE /api/v1/external-providers/{providerId}` (يتطلب `providers.edit` و`CSRF`): يتحقق من عدم ارتباط المزود الخارجي بوثائق API قائمة (`422` إن وُجد ارتباط)، ثم يحذفه ويسجل `EXTERNAL_PROVIDER_DELETED`.
2. **في الواجهة (`masterDataApi.ts` و`ProvidersManagementPage.tsx`):**
   - تبسيط عنوانَي التبويبين إلى مسميين نظيفين فقط: **«مزودون داخليون»** و**«مزودون خارجيون»** (حذف العبارات التوضيحية بين القوسين).
   - حذف صندوق التنبيه (`info-box`)، وحذف العناوين الداخلية (`الأنظمة المزودة الداخلية (UI-03 · M02)`) والأوصاف الطويلة.
   - حذف شريط البحث والتصفية (`ابحث باسم المزود...` و`كل الحالات`).
   - حذف عمود `الوثائق المرتبطة` من الجدولين ليقتصر الجدول على الأعمدة الأساسية (`الاسم`، `الوصف`، `الحالة`، `الإجراءات`).
   - استبدال زر الإضافة النصي الكبير بزر أيقونة `+` مدمج (`compact-add-icon-btn`) في زاوية البطاقة لا يشغل مساحة رأسية.
   - إضافة زر **«حذف»** في عمود الإجراءات للمزودين الداخليين والخارجيين مع نافذة تأكيد الحذف في `CentralModalDialog`.

**نطاق التنفيذ:**
- **المطلوب تنفيذه:** تحديث `MasterDataModule.cs`، و`MasterDataService.cs`، و`masterDataApi.ts`، و`ProvidersManagementPage.tsx`.
- **ما لا يدخل ضمن المهمة:** تعديل مخطط قاعدة البيانات.

**معايير الاكتمال:**
- [ ] اختفاء النصوص والأكواد الزائدة (`UI-03 · M02`)، وصندوق التنبيه، وشريط البحث، وعمود الوثائق من شاشة الأنظمة المزودة.
- [ ] وجود زر `+` مدمج للإضافة وزر «حذف» فعال في عمود الإجراءات للمزودين الداخليين والخارجيين.
